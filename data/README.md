# Data

The Ausgrid files are not stored in this repository (size and licence).

1. Download the half-hour data for 2011-2012 and 2012-2013 from the [Data.NSW page of the dataset](https://data.nsw.gov.au/data/dataset/solar-home-electricty-data).
2. Unzip them here so that the folder looks like this:

```
data/
  Solar home half-hour data - 1 July 2011 to 30 June 2012/
    2011-2012 Solar home electricity data v2.csv
  Solar home half-hour data - 1 July 2012 to 30 June 2013/
    2012-2013 Solar home electricity data v2.csv
```

You can also keep the files elsewhere and set the environment variable `AUSGRID_DATA_DIR` to that folder.
